# 模組規格：Streamlit 互動介面 (docs/modules/04_app.md)

本文件定義 Streamlit 儀表板（`app/`）之實作規格與驗收標準。

---

## 1. 核心檔案
- 實作檔案：`app/main_app.py`（含 `app/__init__.py`）
- 啟動指令：`streamlit run app/main_app.py`
- 驗收測試：`tests/test_app.py`（無頭無介面數據邏輯斷言與 Streamlit 元件呼叫無崩潰驗證）

---

## 2. 介面結構與功能元件 (刪到不能再刪)

### 2.1 頁面配置與側邊欄 (Sidebar)
- 頁面設定：寬版模式 (`layout="wide"`)，標題 `電腦硬體新品與二手市場比價分析系統`。
- 側邊欄過濾控制項：
  - **零組件大類選單** (`st.sidebar.selectbox`)：`GPU` (預設), `RAM`, `SSD`, `CPU`。
  - **規格群組選單** (`st.sidebar.selectbox`)：依選定大類從資料庫動態載入（例如 `RTX 4060 Ti 16G`、`DDR5-6000 32G`）。
  - **過濾開關**：
    - `[x] 排除商業工作室貼文` (`st.sidebar.checkbox`)：預設勾選。
    - `[x] 僅看原廠保固內商品` (`st.sidebar.checkbox`)：預設不勾選。
  - **資料同步控制**：
    - 提供按鈕 `[立即同步原價屋新品報價]`：點擊後觸發 `coolpc_crawler.sync_coolpc_to_db` 並提示成功。

### 2.2 頂部重點指標卡 (Key Metrics Cards)
使用 `st.columns(4)` 橫向展示核心數值：
1. **今日新品最低價**：顯示 $NT 價格，並附帶歷史 90 天位階（例如：`第 15 百分位 (低檔)`）與降價標籤。
2. **二手市場中位價**：顯示個人自售中位數，無自售時顯示全體中位數。
3. **二手折數**：例如 `72.5 折`。
4. **轉買二手可省金額**：例如 `節省 $4,500 元`。

### 2.3 中段 Plotly 視覺化圖表區 (Charts)
使用 `st.columns(2)` 左右並排：
- **左圖：新品 90 天歷史價格走勢圖 (`plotly.graph_objects`)**
  - 歷史每日價格折線 (`mode='lines+markers'`)。
  - 標示水平參考線：歷史最高價 (紅虛線)、歷史最低價 (綠虛線)、歷史均價 (灰虛線)。
  - 圖表標題標示真假降價警語或位階。
- **右圖：跨市場與賣家類型價格對比直條圖 (`plotly.express` 或 `graph_objects`)**
  - 對比「今日新品最低價」、「FB 個人自售均價」、「PTT 個人自售均價」、「FB 工作室均價」。
  - 橫條/直條標示價格與價差，清晰呈現跨平台行情差異。

### 2.4 下方即時二手比價列表 (Listings Table)
- 查詢當前選定 `spec_group` 之二手貼文，依貼文時間降冪排列。
- 依側邊欄開關過濾（排除工作室、保固篩選）。
- 呼叫 `evaluate_listing_price` 為每筆貼文即時評估，顯示對比均價差額、折數與醒目標籤：
  - 🟢 `低於行情 (推薦購買)`
  - 🟡 `符合行情`
  - ⚪ `偏貴 (建議買新品)`
  - 🔴 `異常低價警示 (防詐騙/故障)`
- 欄位包含：平台、發文時間、賣家名稱、賣家類型、完整型號規格、開價、對比行情價差、新品折數、系統行情評估標籤、原文連結。

---

## 3. 容錯與空狀態防護 (Graceful Degradation)
- 當資料庫為空或該規格無貼文時，呈現引導提示訊息（`st.info("目前尚無此規格之二手貼文資料，請點擊側邊欄同步按鈕或先執行爬蟲入庫。")`），絕不噴出黃色/紅色崩潰堆疊追蹤。
